# ES-DE: Creating RetroDECK Themes

RetroDECK includes additional systems that are not natively supported by
ES-DE. If you are an ES-DE theme developer, you can add RetroDECK support to your theme.

## Official RetroDECK Theme

Use the official RetroDECK theme as a reference and starting point:

[RetroDECK Theme](https://github.com/RetroDECK/RetroDECK-theme)
