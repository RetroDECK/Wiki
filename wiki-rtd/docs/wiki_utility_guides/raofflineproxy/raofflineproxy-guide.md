# RAOfflineProxy - General Guide

<img src="../../../wiki_images/logos/raofflineproxy-logo.png" width="150" alt="RAOfflineProxy logo">

RAOfflineProxy (RetroAchievements Offline Proxy) is a local proxy that enables users to earn **casual** RetroAchievements without an active internet connection.

The proxy caches game achievement data locally while online, allowing achievements to be unlocked during offline use. Upon reconnecting, earned achievements are automatically synced to the user's RetroAchievements account.

### Hardcore Mode Restriction

Hardcore mode is **not supported** when the proxy is enabled. All achievements are restricted to casual mode only and any hardcore unlocks are immediately rejected. 

Enableing the proxy in RetroDECK automatically disables hardcore mode in supported emulator configurations when started and restores the previous settings upon stopping.
