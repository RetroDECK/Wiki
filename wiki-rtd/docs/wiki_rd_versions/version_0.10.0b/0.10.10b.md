## RetroDECK

<img src="../../../wiki_icons/retrodeck/icon-framework.svg" width="75" alt="RetroDECK Framework Icon">


**Changed:**

- **Framework:** Upgraded to org.kde.Platform 6.11.

**Fixed:**

- **Bios Checker:** Added and corrected MD5 hash values.

- **ES-DE:** Prevented helper templates from overwriting custom Rules and Systems.

- **Framework:** Fixed Flatpak library pathing error in manifest.

- **RetroArch:** Resolved compatibility issue with genesis_plus_gx_paprium_libretro core.

- **Vita3K:** Resolved longstanding org.kde.Platform compatibility issue blocking updates.
