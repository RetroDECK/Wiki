# RetroDECK v0.10.10b

<img src="../../../wiki_images/logos/rd-logo-box.png" width="600" alt="Rd Logo Box logo">

**Release date:** 2026-10-XX

One tiny patch of fixes, component updates and a major org.kde.Platform update.

---

## RetroDECK Framework

<img src="../../../wiki_icons/retrodeck/icon-framework.svg" width="75" alt="RetroDECK Framework Icon">

**Added:**

- **PPSSPP:** Exposed `PSP/GAME` to `retrodeck/storage/PPSSPP/GAME`.
- **PPSSPP-Core:** Exposed `retroarch/saves/PPSSPP/PSP/GAME` to `retrodeck/storage/retroarch-core/PPSSPP/GAME`.
- **PPSSPP-Core:** Exposed `retroarch/saves/PPSSPP/PSP/shaders` to `retrodeck/shaders/retroarch-core/PPSSPP/shaders`.

**Changed:**

- **Framework:** Upgraded to org.kde.Platform 6.11 (A major feat).

**Fixed:**

- **Bios Checker:** Added and corrected MD5 hash values.
- **ES-DE:** Prevented helper templates from overwriting custom Rules and Systems.
- **Icons:** Resolved multiple icon alignment and background issues.
- **Framework:** Fixed Flatpak library pathing error in manifest.
- **RetroArch:** Resolved compatibility issue with `genesis_plus_gx_paprium_libretro` core.
- **RetroArch:** Resolved config issues with `MelonDS DS` core with openg renderer and the amount of selectable layouts.
- **Vita3K:** Resolved longstanding org.kde.Platform compatibility issue blocking updates.

**Reset:**

- **MelonDS (Standalone):** Configuration must be reset due to the upgrade and changes to the `melonDS.toml` structure.
