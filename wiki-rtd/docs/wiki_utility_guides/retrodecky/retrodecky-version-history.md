## 0.0.4

### Release Date

2026-03-21

### Notes

- Moved from BSD to GPL3 license (to match with RetroDECK and adviced by the RetroDECK Team), also included other licenses from RetroDECK Team.

- Created a proper TXT viewer.
- Allow to add custom PDF or TXT documents per game.
- Added a button to open the RetroDECK Wiki in the browser.

## 0.0.3

### Release Date

2026-03-15

### Notes

The plugin name was changed from RetroDecky to RetroDECKY. Make sure to uninstall any previous version of RetroDecky in Decky before installing this new version.

- Added experimental feature which launches RetroDECK when gaming mode is entered.
- Allow to view controller hotkeys for actions via an info icon.
- Added Manual Viewer as experimental feature which has to be enabled in the settings.
- Updated logos and readme by Lazorne (RetroDECK Team).
