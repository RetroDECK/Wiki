## RetroDECK Framework

<img src="../../../wiki_icons/retrodeck/icon-framework.svg" width="75" alt="RetroDECK Framework Logo">

Following the 0.10.0 rewrite, RetroDECK has been further modularized making it even more dynamic then before.

**Added:** 

- **Shutdown / Startup Hooks:** Components can trigger functions on `startup` and `shutdown` via `component_functions.sh`.
- **Component Isolation:** All component-specific logic relocated to respective component modules.
- **Dynamic Loading:** Components load dynamically at boot and populates tools, functions and ES-DE launch commands registered automatically on startup.

**Changes:**

**Unified Ingrediens:** `component_update.sh` and `component_prepare.sh` merged into `component_functions.sh`.
