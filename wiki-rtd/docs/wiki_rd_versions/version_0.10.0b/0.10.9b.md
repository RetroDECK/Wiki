## RetroDECK Framework

<img src="../../../wiki_icons/retrodeck/icon-framework.svg" width="75" alt="RetroDECK Framework Icon">

**Fixed:**

- **RetroArch:** Fixed unconfigured LRPS2 directory mappings to align with RetroDeck core directories (saves, cheats, texture_packs, shaders, bios).
 
- **RetroArch:** Readded missing retroarch screenshot folder in retrodeck/screenshots that was gone in some installations.

- **RetroArch:** Added missing bios asset folders for: cannonball, dinothar, DirkSimple, dolphin-emu (core), nxengine, pcsx2 (LRPS2), ppsspp (core), qemu, and xrick in retrodeck/bios.

- **RetroArch:** Added missing assets files: ecwolf.pk3 and prboom.wad in retrodeck/bios.
